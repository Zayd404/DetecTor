# Changelog

Semua perubahan penting pada proyek **DetecTor** akan dicatat dalam file ini.

## - 2026-11-25
### Ditambahkan
- Modul **Web Reconnaissance** (DNS, Domain, HTTP Headers, SSL/TLS, Technology Detection, IP Recon, dan Attack Surface).
- Modul **People OSINT** (Pencarian Username, Pencarian Nama, dan Pembuat Tautan Profil Publik).
- Sistem pelaporan otomatis dalam format **JSON** dan **TXT**.
- Antarmuka terminal interaktif berbasis `rich`.
